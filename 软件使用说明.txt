辐射制冷涂料建筑节能计算工具
软件使用说明
============================================================

适用软件版本：0.1.0-test（Windows 64 位离线安装版）
内置 OpenStudio：3.11.0
内置 EnergyPlus：26.1.0
说明书编制日期：2026-08-27


一、软件用途
============================================================

本软件用于比较同一建筑在“未使用辐射制冷涂料”和“使用辐射制冷涂料”
两种工况下的全年建筑能耗，并计算制冷用电降低百分比。

用户只需要准备：

1. 按模板填写的建筑参数 Excel 文件；
2. 与建筑所在地对应的 EPW 气象文件；
3. 用于保存计算结果的文件夹。

软件会自动完成：Excel 数据检查、OpenStudio 建模、OSM/IDF 生成、IDF
版本转换、几何质量检查、基准模型与涂层模型生成、两种工况的 EnergyPlus
全年模拟，以及能耗和节电率统计。

本软件的主要结果包括：

1. 制冷主设备全年用电量；
2. 制冷系统综合用电量；
3. 建筑全年总用电量；
4. 供暖全年用电量；
5. 制冷峰值功率；
6. 上述指标在基准工况和涂层工况之间的变化率；
7. 8760 小时或闰年 8784 小时的制冷用电对比数据。


二、计算原理和结果含义
============================================================

1. 基准工况

   使用 Excel 中填写的原建筑围护结构外表面太阳吸收率、热吸收率和其他
   建筑参数建立模型。

2. 涂层工况

   软件复制基准模型，只修改指定屋顶或外墙构造最外层材料的太阳吸收率和
   长波发射率。其他建筑几何、构造层次、内部负荷和运行条件保持不变。

3. 太阳反射率换算

   太阳吸收率 = 1 - 太阳反射率

4. 制冷节电率

   制冷节电率 =
   （基准制冷用电量 - 涂层制冷用电量）÷ 基准制冷用电量 × 100%

   结果为正值：涂层工况制冷用电减少；
   结果为 0：两种工况制冷用电相同；
   结果为负值：涂层工况制冷用电增加；
   结果显示“—”：基准制冷用电为零，无法定义节电率。

5. 供暖变化率

   供暖指标使用“变化率”而不是“节省率”：

   供暖变化率 =
   （涂层供暖用电量 - 基准供暖用电量）÷ 基准供暖用电量 × 100%

   正值表示供暖用电增加，负值表示供暖用电减少。分析辐射制冷涂料时，
   应同时考虑夏季制冷收益和冬季供暖代价。

6. 数据来源

   年度能耗由 EnergyPlus SQLite 中天气运行期的逐时记录汇总得到。软件会
   检查基准与涂层模型的时间戳是否一致、逐时记录是否完整、逐时合计与
   年度结果是否一致，并拒绝包含 Severe 或 Fatal 错误的结果。


三、适用范围与重要限制
============================================================

1. 当前版本把辐射制冷涂料视为热阻和热容可以忽略的薄膜，通过改变目标
   构造最外层材料的太阳吸收率和长波发射率表示涂层作用。

2. “涂料”工作表中的厚度和导热系数会被读取和保存，但当前薄膜等效模型
   不使用它们改变构造热阻或热容。

3. 当前使用 EnergyPlus 的宽波段长波发射率模型，不包含 8～13 μm 大气
   窗口的逐波长光谱耦合。需要研究光谱选择性材料时，应另行开发光谱模型
   或 EnergyPlus Python API 逐时间步耦合。

4. 当前只允许目标表面 100% 涂覆，即“涂覆面积比例”必须填写 1。部分
   涂覆必须先把建筑表面拆分成独立几何区域，不能直接填写 0.5 等比例。

5. 涂层目标构造的最外层材料必须是 Material 或 Material:NoMass。
   绿化屋面、复杂窗系统、生态屋面和自定义边界模型不属于当前自动处理范围。

6. 门窗输入虽然提供“窗墙比”和“明确尺寸”两个选项，但当前自动建模仅
   支持“窗墙比”。正式计算请使用窗墙比模式。

7. 当前只启用 HVAC 工作表的第一条系统记录，并把该系统作为所有计算的
   活动系统。若需要多个系统，应先把各系统合并为一条等效系统，或者扩展
   当前模型生成程序。

8. 当前只启用“涂料”工作表的第一条方案。比较不同涂料或不同老化状态时，
   应分别制作 Excel 文件并单独运行，或者把待计算方案放在第一条数据行。

9. “简化定COP空调”由分区热泵表示。填写的送风机功率会分配到各服务热区；
   当前独立水泵功率尚未计入该分区热泵模型。水系统建筑需要进一步建立
   设备级模型后，才能把水泵能耗作为真实结果使用。

10. “IdealLoads仅负荷”适合查看冷热负荷，不适合直接代表真实空调设备
    制冷用电。研究节电率时优先使用具有真实或校准 COP 的简化定 COP 系统。

11. 渗透换气在当前模型中按全天启用处理；人员、照明和设备按指定时间表
    运行。周六和周日启用后沿用工作日的起止时刻和峰值比例。

12. 温控工作表中的制冷和采暖设定温度当前按恒定设定值建模；HVAC 运行
    时间由所引用的运行时间表控制。

13. 软件输出是由输入数据和模型假设得到的模拟结果。未经实际能耗校准的
    结果适合方案比较，不应直接作为实际节电量保证或合同结算依据。


四、安装与卸载
============================================================

4.1 系统要求

1. Windows 10 或 Windows 11，64 位系统；
2. 建议至少 8 GB 内存；复杂建筑建议 16 GB 或更多；
3. 安装包约 360 MB，安装后建议预留至少 2 GB 磁盘空间；
4. 每个项目还需要额外结果空间，复杂模型或多次计算可能占用数 GB；
5. 离线安装版不需要另行安装 Python、OpenStudio 或 EnergyPlus。

4.2 下载地址

发布页面：
https://github.com/SfMiku-user/energyplus-coating-tool/releases/tag/v0.1.0-test

安装包：
https://github.com/SfMiku-user/energyplus-coating-tool/releases/download/v0.1.0-test/EnergyPlusCoatingTool-0.1.0-test-windows-x64-setup.exe

安装包文件名：
EnergyPlusCoatingTool-0.1.0-test-windows-x64-setup.exe

安装包 SHA-256：
F8C9BB72067420B0CB2947E5F6E9C13C940630579AE9BD2D3C602A8C13335EFF

4.3 可选的完整性校验

打开 PowerShell，执行：

Get-FileHash -Algorithm SHA256 "安装包完整路径"

将输出值与上述 SHA-256 比较。两个值必须完全相同。

4.4 安装步骤

1. 双击安装包；
2. 阅读第三方软件许可证提示；
3. 选择安装目录，通常保持默认即可；
4. 根据需要选择是否创建桌面快捷方式；
5. 点击安装；
6. 安装完成后，可直接启动软件。

当前测试版没有商业代码签名证书。Windows SmartScreen 可能显示“Windows
已保护你的电脑”。确认安装包来自上述 GitHub 地址且 SHA-256 一致后，可
点击“更多信息”，再点击“仍要运行”。

默认安装位置通常为：

%LOCALAPPDATA%\Programs\EnergyPlusCoatingTool

安装目录中的 runtimes 文件夹包含 OpenStudio 和 EnergyPlus。不要移动、
重命名或删除 runtimes 及其内部文件，否则一键计算将无法运行。

4.5 卸载步骤

在 Windows“设置—应用—已安装的应用”中找到“辐射制冷涂料建筑节能计算
工具”，选择卸载。卸载不会删除用户另行选择的结果目录。用户设置可能保留在：

%LOCALAPPDATA%\EnergyPlusCoatingTool\settings.json

如需完全清除个人路径记录，可在卸载后手工删除上述 settings.json。


五、第一次启动和界面说明
============================================================

主界面包括以下五个路径输入框：

1. 建筑参数 Excel
   选择填写完成的 .xlsx 文件。首次启动通常会自动指向安装包内的
   sample_projects\示例办公楼.xlsx。

2. 建筑所在地 EPW
   选择实际建筑所在地或最接近气象站的 .epw 文件。界面中选择的 EPW 是
   本次模拟实际使用的文件，优先于 Excel“项目信息”中的 epw_path 文字记录。

3. 结果保存目录
   指定所有计算结果的上级目录。离线安装版默认位置为：
   “文档\EnergyPlus Coating Tool Results”。建议选择空间充足、具有写入权限
   且便于备份的位置。

4. OpenStudio 3.11
   离线安装版会自动识别内置 openstudio.exe，通常不需要修改。

5. EnergyPlus 26.1
   离线安装版会自动识别内置 energyplus.exe，通常不需要修改。

界面按钮：

1. “开始一键计算”：检查路径后启动全部计算；
2. “打开输入模板”：打开安装目录中的空白建筑参数模板；
3. “打开最近结果”：计算成功后打开本次运行目录；
4. “选择……”或“选择目录……”：重新选择对应文件或目录。

软件会保存上次选择的 Excel、EPW、结果目录和程序路径。下次启动时无需
重复选择。如文件被移动或删除，需重新选择。


六、输入文件准备
============================================================

6.1 建筑参数 Excel

空白模板：templates\建筑参数输入模板.xlsx
示例项目：sample_projects\示例办公楼.xlsx

正式使用时建议：

1. 复制空白模板；
2. 将副本改名为“项目名称_建筑参数.xlsx”；
3. 在副本中填写数据，不直接修改空白母版；
4. 填完后保存并关闭 Excel，再开始计算；
5. 每次重大修改保留一个新版本，例如 V01、V02、V03。

6.2 EPW 气象文件

EPW 文件应与建筑所在地、经纬度、海拔、时区和气候区相匹配。对于真实
建筑研究，应优先使用与研究目的相符的典型气象年或实测年份气象文件。

安装目录 examples 中的 Chicago EPW 只用于确认软件能够运行，不能用于
郑州或其他城市的真实节能结论。

6.3 结果目录

软件每次运行都会在结果目录下创建新的时间戳文件夹，不会覆盖以前的结果。
不要把结果目录设置为安装目录、OpenStudio 目录或 EnergyPlus 目录。


七、Excel 填写通用规则
============================================================

1. 不要修改工作表名称。

2. 不要修改第一行的表头名称、顺序或单位。

3. 所有数值只填写数字，不要在单元格中追加 m、m2、W、kW、% 等单位。
   例如 0.2 m 应填写 0.2，35% 应填写 0.35。

4. 编号必须是非空文本，并在同一工作表内保持唯一。建议只使用英文字母、
   数字和下划线，例如 F01、Z001、MAT_ROOF、CON_ROOF01。

5. 引用其他工作表的编号时必须完全一致，包括大小写、空格和下划线。

6. 一个单元格填写多个编号时，使用英文分号“;”分隔，不要使用中文分号。

7. 坐标中的 x、y 使用英文逗号“,”分隔，各坐标点使用英文分号“;”分隔。

8. “是/否”字段使用下拉选项或准确填写“是”或“否”。

9. 使用下拉选项的字段优先从列表选择，不要自行创造拼写相近的选项。

10. 数据区中间不要插入整行空白。读取程序遇到第一条全空行后，会把该行
    之后的内容视为说明内容并停止读取。

11. 不要删除必填工作表。缺少任一必填工作表时，软件会停止转换并指出
    缺少的工作表名称。

12. 可以增加数据行，但不要破坏现有格式、批注和下拉列表。复制新增行时，
    建议从上一条格式正确的数据行整行复制后再修改。

13. 黄色单元格为需要用户替换的示例输入。示例值不能直接代表真实建筑。

14. 每行“备注”应记录参数解释、特殊假设或需要复核的问题。


八、数据来源类型说明
============================================================

“数据来源类型”只允许使用以下英文值：

1. measured
   现场测量或实验室实测数据，例如表面反射率、实际温度、实测功率。

2. drawing
   一般图纸或测绘图数据，但不一定是正式设计施工图。

3. design_drawing
   建筑、结构、暖通等正式设计图或竣工图数据。

4. equipment_manual
   设备铭牌、产品样本、设备手册或制造商技术资料。

5. operation_record
   运行记录、值班记录、控制系统记录、能耗账单或使用时间调查。

6. standard_default
   国家标准、行业标准、地方标准或软件标准默认值。

7. assumption
   暂时无法获得真实数据时采用的工程假设。使用该选项时必须在备注中写明
   假设依据，并在最终报告中进行敏感性分析。

8. calibrated
   通过实测能耗、室内温度或设备运行数据对模型校准后得到的参数。


九、各工作表详细填写方法
============================================================

9.1 “填写说明”工作表

该表只用于阅读，不参与模型计算。不要删除其他工作表，也不要修改工作表
名称和表头。

9.2 “项目信息”工作表

采用“字段键—填写值”形式填写：

1. schema_version：固定为 1.0，不要修改；
2. name：项目名称；
3. building_type：建筑用途，例如办公、住宅、学校；
4. epw_path：用于追溯的气象文件记录；本次运行实际采用界面选择的 EPW；
5. longitude：经度，范围 -180～180；
6. latitude：纬度，范围 -90～90；
7. elevation_m：海拔，单位 m；
8. time_zone：时区，中国标准时间通常填写 8；
9. north_axis_deg：建筑相对正北顺时针旋转角度；
10. total_floor_area_m2：总建筑面积。虽然可以留空，但正式项目应填写，
    软件会用它核对模型总楼面面积；
11. year_built：建成年份，用于记录建筑和设备年代。

经纬度、海拔和时区应尽量与 EPW 站点相符。建筑北向角应来自总平面图，
否则不同朝向太阳辐射会产生偏差。

9.3 “楼层”工作表

每个实际建模楼层填写一行：

1. 楼层编号：唯一编号，例如 F01；
2. 标高_m：该层地面相对建筑基准点的标高；
3. 层高_m：楼面到上一层楼面的高度，必须大于 0；
4. 倍数：完全相同的重复楼层可使用倍数，普通楼层填写 1；
5. 数据来源类型：通常使用 design_drawing；
6. 备注：填写首层、标准层、设备层等说明。

相邻楼层标高和层高必须协调。中间楼层几何应上下对齐，使楼板与上一层
地面能够自动匹配，避免中间楼层被识别为室外屋顶。

9.4 “热区”工作表

每个热区填写一行：

1. 热区编号：唯一编号，例如 Z001；
2. 楼层编号：必须在“楼层”表中存在；
3. 热区名称：便于识别的中文名称；
4. 地面多边形坐标_m：格式为 x1,y1;x2,y2;x3,y3；
5. 是否空调：填写“是”或“否”；
6. 空间用途：办公室、会议室、走廊等；
7. 热区倍数：普通热区填写 1；
8. 数据来源类型和备注：记录图纸来源及假设。

矩形 8 m × 6 m 示例：

0,0;8,0;8,6;0,6

坐标填写要求：

1. 至少三个不共线坐标点；
2. 同一楼层所有热区使用同一坐标原点和方向；
3. 坐标点沿顺时针或逆时针连续排列；
4. 不要重复首尾点；
5. 多边形不要自交；
6. 相邻空间的公共边界坐标必须准确一致；
7. 上下对应空间的平面边界应一致或按真实退台准确建模。

9.5 “门窗”工作表

当前版本每条记录用于在指定热区某一朝向的室外墙上生成窗：

1. 门窗编号：唯一编号；
2. 热区编号：必须在“热区”表中存在；
3. 输入方式：正式计算请选择“窗墙比”；
4. 方向：只能是 North、East、South、West；
5. 窗墙比：0～1 之间且不能等于 0 或 1，例如 0.35；
6. 宽度、高度、窗台高：当前窗墙比模式留空；
7. 窗构造编号：必须在“窗构造”表中存在；
8. 遮阳类型：用于记录遮阳情况；当前自动模型尚未生成详细遮阳几何；
9. 数据来源类型和备注：记录立面图、门窗表或实测来源。

如果一个热区没有对应方向的室外墙，软件会报“没有朝向某方向的外墙”。
如果窗面积超过墙面可容纳范围，几何验收会停止计算。

9.6 “窗构造”工作表

1. 窗构造编号：供“门窗”表引用；
2. 名称：玻璃窗名称；
3. EnergyPlus类型：当前使用 WindowMaterial:SimpleGlazingSystem；
4. 整窗U值_W_m2K：必须大于 0；
5. 太阳得热系数_SHGC：0～1；
6. 可见光透射率：0～1；
7. 数据来源类型：优先 equipment_manual 或 measured；
8. 备注：记录玻璃、窗框及检测条件。

U 值应尽量使用整窗值，而不是只使用玻璃中心值。

9.7 “材料”工作表

每种不透明围护材料填写一行。支持：

1. Material：有质量实体材料；
2. Material:NoMass：无质量材料；
3. Material:AirGap：空气层。

Material 应填写：粗糙度、厚度、导热系数、密度、比热、热吸收率、太阳
吸收率和可见光吸收率。

Material:NoMass 应填写：粗糙度、热阻、热吸收率、太阳吸收率和可见光
吸收率。

Material:AirGap 主要填写热阻。注意：当前 OpenStudio 自动生成模块实际支持
生成 Material 和 Material:NoMass；含 AirGap 的正式模型应先进行单独验证。

常见粗糙度选项包括：

VeryRough、Rough、MediumRough、MediumSmooth、Smooth、VerySmooth。

所有厚度、导热系数、密度、比热和热阻应为正数；各吸收率范围为 0～1。

9.8 “构造”工作表

1. 构造编号：唯一编号；
2. 名称：屋面、外墙、地面等构造名称；
3. 用途：至少应具有“屋顶”和“外墙”构造，正式项目还应填写“地面”或
   “楼板”构造；
4. 从室外到室内材料层：材料编号按室外到室内顺序排列，使用英文分号分隔；
5. 外表面材料编号：必须等于材料层列表中的第一层；
6. 数据来源类型和备注：记录构造做法表或设计图编号。

示例：

MAT_FINISH;MAT_INS;MAT_CONCRETE

若把辐射制冷涂料用于某构造，该构造最外层材料必须是当前可修改的
Material 或 Material:NoMass。

9.9 “时间表”工作表

1. 时间表编号：唯一编号；
2. 类型：Fraction、OnOff 或 Temperature；
3. 工作日起始、工作日结束：使用 Excel 时间值，例如 08:00、18:00；
4. 周六启用、周日启用：填写“是”或“否”；
5. 峰值比例：0～1；
6. 数据来源类型和备注：优先记录实际运行调查或控制系统数据。

结束时间必须晚于起始时间。当前每个时间表只支持一个日运行时间段；周末
启用时使用相同起止时刻和峰值比例。如需午休、多班次或节假日规则，需要
扩展时间表生成模块。

9.10 “人员与设备”工作表

每个热区最多填写一条记录：

1. 热区编号；
2. 时间表编号；
3. 人员密度，单位 person/m2；
4. 照明功率密度，单位 W/m2；
5. 设备功率密度，单位 W/m2；
6. 渗透换气次数，单位 ACH；
7. 新风量，单位 L/s·person；
8. 数据来源类型和备注。

所有数值应大于或等于 0。正式研究应优先使用现场调查、设备清单、照明图、
新风设计资料和运行监测数据。

9.11 “温控”工作表

每个热区最多填写一条记录：

1. 热区编号；
2. 制冷设定温度；
3. 采暖设定温度；
4. 时间表编号；
5. 数据来源类型和备注。

制冷设定温度必须高于采暖设定温度。当前设定温度按恒定值建模，时间表
主要用于关联 HVAC 运行时段。

9.12 “HVAC”工作表

主要字段：

1. 系统编号：唯一编号；
2. 系统类型：建议使用“简化定COP空调”；
3. 服务热区编号：多个热区使用英文分号分隔；
4. 制冷COP、采暖COP：必须大于 0；
5. 额定制冷容量_kW：已知时填写；未知时可留空，由模型自动定容；
6. 送风机功率_W：可填写 0 或实测/铭牌功率；
7. 水泵功率_W：可以记录，但当前分区热泵模型尚未计入独立水泵能耗；
8. 部分负荷曲线：当前“默认定COP”主要用于记录；
9. 运行时间表编号：必须在“时间表”中存在；
10. 数据来源类型和备注。

当前只启用第一条 HVAC 记录。所有标记为“是否空调=是”的热区原则上都应
被活动 HVAC 系统服务。未服务热区会产生警告并影响结果可信度。

9.13 “涂料”工作表

主要字段：

1. 方案编号：唯一编号；
2. 涂料名称；
3. 涂覆对象类型：填写“屋顶构造”或“外墙构造”；
4. 目标构造编号：必须在“构造”表中存在；多个编号用英文分号分隔；
5. 太阳反射率：0～1，优先使用太阳光谱反射率积分值；
6. 长波发射率：0～1，优先使用实测半球发射率；
7. 厚度_m：正数，用于数据存档；
8. 导热系数_W_mK：正数，用于数据存档；
9. 状态：例如初始、老化、污染、清洗后；
10. 涂覆面积比例：当前必须填写 1；
11. 老化年数：初始状态通常填写 0；
12. 数据来源类型：优先 measured；
13. 备注：记录检测标准、仪器、样品批次和测试日期。

当前只计算第一条涂料记录。涂料参数应来自正式检测报告；不要直接使用
产品宣传页中的单点峰值反射率代替全太阳光谱积分反射率。

9.14 “数据质量”工作表

用于记录关键参数的可追溯信息：

1. 章节：例如 coating、hvac、materials；
2. 记录编号：对应涂料、HVAC、材料等编号；
3. 参数字段：建议使用英文数据字段名；
4. 数据来源类型；
5. 来源文件或设备；
6. 不确定度；
7. 置信度；
8. 复核状态；
9. 备注。

建议至少记录太阳反射率、长波发射率、制冷 COP、围护结构热物性、人员和
设备负荷、运行时间表、气象文件来源等关键数据。


十、运行操作步骤
============================================================

10.1 使用示例项目测试

1. 启动软件；
2. “建筑参数 Excel”选择 sample_projects\示例办公楼.xlsx；
3. “建筑所在地 EPW”可选择 examples 中的示例 EPW；
4. 选择结果保存目录；
5. 确认 OpenStudio 和 EnergyPlus 路径存在；
6. 点击“开始一键计算”；
7. 等待进度达到 100%；
8. 查看界面结果，点击“打开最近结果”。

示例建筑和示例 EPW 仅用于功能测试。二者城市不一致时，计算结果没有真实
工程含义。

10.2 计算真实建筑

1. 根据设计图复制并填写建筑参数模板；
2. 用设备资料和运行记录填写 HVAC、人员、设备和时间表；
3. 用检测报告填写涂料参数；
4. 选择建筑所在地对应 EPW；
5. 选择新的结果上级目录；
6. 点击“开始一键计算”；
7. 计算过程中不要关闭软件、移动输入文件或修改安装目录；
8. 计算成功后检查界面结果及全部验收报告；
9. 把 Excel、EPW、整个运行目录一并归档。

示例项目通常约需 1 分钟。大型建筑、热区较多或计算机性能较低时可能需要
更长时间。请以界面状态和进度条为准。

10.3 进度阶段

约 5%：读取并校验 Excel；
约 20%：生成并验收建筑几何模型；
约 45%：生成基准和涂层模型，并运行两种工况；
约 85%：核对全年逐时记录并计算节电率；
100%：结果生成完成。


十一、软件自动执行的验收
============================================================

模型进入能耗计算前会自动检查：

1. 必填工作表、表头和字段是否完整；
2. 数值范围和数据类型是否正确；
3. 编号是否重复、引用编号是否存在；
4. 未匹配内部表面是否为零；
5. 项目声明面积、热区多边形面积和模型楼面面积是否一致；
6. 是否存在重复空间；
7. 是否存在负面积或无效表面；
8. 窗户是否超出墙面；
9. 中间楼层是否被错误识别为外屋顶；
10. 基准模型是否保持不变；
11. 涂层模型是否只修改目标构造；
12. 基准与涂层模型几何是否完全一致；
13. 涂层光学参数是否正确写入；
14. 两次 EnergyPlus 运行是否没有 Severe/Fatal 错误；
15. 是否具有完整 8760 或 8784 小时记录；
16. 两种工况时间戳是否完全一致；
17. 逐时能耗是否非负且年度汇总一致；
18. 制冷节电率是否可以有效计算。

任一关键检查不通过时，软件停止后续流程，保留错误记录，不会输出一个看似
完整但实际不可信的最终节电率。


十二、结果目录和文件说明
============================================================

每次运行创建类似以下目录：

结果保存目录\
└─ run_年月日_时分秒_微秒\
   ├─ input\
   ├─ generated_model\
   ├─ coating_model\
   ├─ results\
   └─ workflow_manifest.json

12.1 input 文件夹

1. 建筑参数输入.xlsx
   本次运行使用的 Excel 副本。即使原 Excel 后续被修改，仍可追溯本次输入。

2. project.json
   Excel 转换后的标准化项目数据，供程序和高级用户检查。

12.2 generated_model 文件夹

常见文件包括：

1. project.json：模型生成阶段使用的项目数据；
2. baseline.osm：OpenStudio 模型；
3. baseline_25_2.idf：OpenStudio 生成的原始 IDF；
4. baseline.idf：转换为 EnergyPlus 26.1 格式的基准 IDF；
5. openstudio.log：OpenStudio 建模日志；
6. transition.log：IDF 版本转换日志；
7. build_manifest.json：模型生成清单；
8. geometry_validation.json：几何验收报告。

12.3 coating_model 文件夹

常见文件包括：

1. baseline.idf：用于对比计算的基准模型；
2. coating.idf：应用涂层后的模型；
3. coating_validation.json：涂层模型差异验收报告；
4. stage7_manifest.json：涂层方案、目标表面和模型文件清单；
5. smoke_test\baseline：基准工况 EnergyPlus 全部输出；
6. smoke_test\coating：涂层工况 EnergyPlus 全部输出。

EnergyPlus 子目录中常见的 eplusout.err 是警告和错误记录，eplusout.sql 是
完整结果数据库，eplusmtr.csv 是计量数据。普通用户不需要逐一打开这些文件，
但应在研究归档时完整保留。

12.4 results 文件夹

1. comparison_results.csv
   最适合直接查看。包含指标、基准工况、涂层工况和变化率。

2. comparison_results.json
   机器可读的完整汇总，包括模型详情、逐时记录数量和警告数量。

3. hourly_cooling_comparison.csv
   逐小时制冷用电对比。主要列包括年月日时分、基准制冷用电、涂层制冷
   用电和每小时节省量。普通年应有 8760 条，闰年可有 8784 条。

4. stage8_validation.json
   最终结果完整性验收报告，all_passed 应为 true，status 应为 passed。

12.5 workflow_manifest.json

本次运行总清单，记录开始和完成时间、输入文件路径、Excel 和 EPW 的
SHA-256、各阶段状态、主要输出路径及最终指标。复现实验时应优先保留该文件。

12.6 workflow_error.json

计算失败时生成，记录失败时间、错误类型、中文错误信息和程序调用信息。
向开发人员反馈问题时，应同时提供该文件以及对应 Excel；涉及保密项目时，
可先对项目名称等敏感信息脱敏。


十三、结果表的正确阅读方法
============================================================

1. 制冷主设备用电
   对应 Cooling:Electricity，主要代表制冷设备电耗。它是计算“制冷用电
   降低百分比”的核心指标。

2. 制冷系统综合用电
   由制冷设备、风机、水泵和排热设备的 EnergyPlus 电表合计得到。若当前
   简化系统没有建立某类设备，该项对应能耗可能为零。

3. 建筑总用电
   对应 Electricity:Facility，包括模型中的全部建筑电力终端。该指标用于
   判断涂层对建筑总电耗的影响。

4. 供暖用电
   用于检查冬季代价。高反射率表面可能降低冬季太阳得热，从而增加供暖需求。

5. 制冷峰值功率
   为全年逐时制冷电量换算得到的最大小时平均功率。可用于评估空调容量和
   电力峰值变化，但不等于更短时间尺度的瞬时最大功率。

6. 推荐报告方式

   至少同时报告：

   （1）制冷主设备基准用电和涂层用电；
   （2）制冷节电率；
   （3）建筑总用电变化率；
   （4）供暖用电变化率；
   （5）制冷峰值变化率；
   （6）EPW 文件名称和年份类型；
   （7）涂料太阳反射率和长波发射率；
   （8）涂覆对象和涂覆面积；
   （9）模型是否经过实际能耗校准；
   （10）所有主要假设和不确定度。


十四、常见错误及处理方法
============================================================

14.1 “请选择有效的建筑参数 Excel”

原因：文件路径为空、文件被移动，或选择的不是 .xlsx 文件。
处理：重新点击“选择……”并选择有效工作簿。

14.2 “缺少工作表”

原因：工作表被删除或改名。
处理：从原始模板恢复工作表名称，把数据复制回对应工作表。

14.3 “第某行某字段不能为空/必须是纯数字”

原因：必填值缺失、数字后附带单位，或填写了无法解析的文本。
处理：根据报错指示的工作表、行号和字段准确修改。

14.4 “数据来源类型不在允许列表中”

原因：没有使用规定的八种英文值。
处理：从下拉列表重新选择，不要输入中文简称。

14.5 “引用的热区/材料/构造/时间表不存在”

原因：编号拼写不一致或被引用记录缺失。
处理：检查两个工作表中的编号是否逐字一致。

14.6 “编号重复”

原因：同一工作表存在两个相同编号。
处理：给每条记录使用唯一编号，并同步修改所有引用处。

14.7 “面积不一致”或几何验收失败

原因：总面积填写错误、热区坐标错误、楼层倍数错误、空间重复、相邻边界
没有对齐或上下楼层不匹配。
处理：对照设计图复核坐标、标高、层高和倍数；查看
generated_model\geometry_validation.json 中失败的检查项。

14.8 “没有朝向 North/East/South/West 的外墙”

原因：门窗方向与热区几何方向不一致，或该热区对应方向不是室外墙。
处理：检查建筑北向角、坐标方向和门窗方向。

14.9 “当前只支持窗墙比输入方式”

原因：选择了“明确尺寸”。
处理：把输入方式改为“窗墙比”并填写 0～1 之间的比例。

14.10 “阶段七当前只允许 100% 涂覆”

原因：涂覆面积比例不是 1。
处理：当前版本填写 1。若真实项目为部分涂覆，需要先拆分几何表面。

14.11 “模型中没有找到符合条件的室外日照屋顶或外墙”

原因：涂覆对象、目标构造编号或构造用途与模型不一致。
处理：确认目标构造确实用于室外屋顶或外墙，且编号填写正确。

14.12 “外层材料不是可修改的 Material 或 Material:NoMass”

原因：目标构造最外层材料类型不受涂层自动修改模块支持。
处理：调整目标构造最外层材料建模方式，或扩展程序支持。

14.13 “EnergyPlus 结果包含 Severe/Fatal”

原因：模型、设备、构造或气象运行出现严重错误。
处理：先查看弹窗信息，再查看 coating_model 下相应工况的 eplusout.err。
不要忽略 Fatal 错误直接引用结果。

14.14 “年度逐时记录不完整”

原因：EPW 不完整、模拟提前终止或输出设置异常。
处理：检查 EPW 完整性和 eplusout.err，确认普通年 8760 小时、闰年 8784 小时。

14.15 计算结果为负节电率

负值不一定是程序错误。可能原因包括涂层降低冬季得热、夜间长波交换、空调
运行方式、内部负荷、目标面积过小或气候不适合。应结合逐时结果和供暖变化
进行分析。

14.16 磁盘空间不足或无法写入

处理：选择剩余空间充足的本地目录，并确认当前账户具有写入权限。清理旧
结果前先备份，不要删除仍需复现的运行目录。


十五、提高真实建筑计算精度的建议
============================================================

1. 几何数据
   使用建筑、结构和幕墙设计图或竣工图；重点复核建筑朝向、热区边界、层高、
   窗墙比和涂覆面积。

2. 围护结构
   使用实际材料厚度、导热系数、密度、比热和表面吸收率。未知夹层不要简单
   删除，应记录假设和来源。

3. 门窗
   使用整窗 U 值、SHGC 和可见光透射率，并确保窗墙比与立面一致。

4. 内部负荷
   根据人员调查、照明图、设备清单和插座功率实测确定，不要直接套用示例值。

5. 运行时间
   使用门禁、BMS、值班记录或问卷建立实际占用和空调运行时段。

6. HVAC
   优先使用设备实测 COP、性能曲线、风机功率和实际容量。当前简化定 COP
   模型适合第一阶段比较；复杂中央空调应扩展为真实系统模型。

7. 涂料参数
   使用与实际基材、施工厚度和老化状态一致的检测值。建议至少记录初始、
   老化和污染状态，并分别运行敏感性分析。

8. 气象数据
   典型年用于长期平均比较，实测年用于对应年度能耗验证。报告中必须写明
   EPW 来源、站点和年份性质。

9. 模型校准
   若要接近真实建筑，应使用电费账单、分项电表、室内温度和设备运行记录
   校准基准模型。当前软件不会自动完成校准，需要研究人员逐步调整输入并
   对比实测数据。

10. 敏感性分析
    对无法准确获得的参数建立多组 Excel 文件，分别改变反射率、发射率、
    COP、运行时间、人员设备负荷、渗透率等，报告结果范围而非单一数字。


十六、结果复现、备份与引用
============================================================

每次正式计算至少保留：

1. 原始设计图和参数来源；
2. 本次建筑参数 Excel；
3. 本次 EPW；
4. 完整 run_... 运行目录；
5. 软件版本号；
6. 安装包 SHA-256；
7. 所有假设、校准记录和人工修改说明。

workflow_manifest.json 已记录 Excel 和 EPW 的 SHA-256，可用于判断后续文件
是否发生改变。不要只保留 comparison_results.csv 而删除模型和验收报告，
否则结果难以审查和复现。


十七、隐私、网络与第三方软件
============================================================

1. 软件在本机读取 Excel、EPW 并执行本地模拟，计算过程不会自动上传建筑
   参数或结果。

2. GitHub 网络仅用于用户自行下载安装包或源码。

3. 安装包内包含未经修改的 OpenStudio 3.11.0 和 EnergyPlus 26.1.0。

4. 第三方许可证位于安装目录中的：

   THIRD_PARTY_NOTICES.txt
   runtimes\OpenStudio-3.11.0\LICENSE.md
   runtimes\EnergyPlus-26.1.0\LICENSE.txt


十八、推荐的最简操作清单
============================================================

1. 复制“建筑参数输入模板.xlsx”；
2. 按真实资料填写全部工作表；
3. 把活动 HVAC 和活动涂料方案放在各自工作表第一条数据行；
4. 门窗选择“窗墙比”；
5. 涂覆面积比例填写 1；
6. 保存并关闭 Excel；
7. 启动软件；
8. 选择 Excel、实际地点 EPW 和结果目录；
9. 确认内置 OpenStudio、EnergyPlus 路径有效；
10. 点击“开始一键计算”；
11. 等待进度达到 100%；
12. 检查 comparison_results.csv；
13. 确认 geometry_validation.json、coating_validation.json 和
    stage8_validation.json 均显示 passed；
14. 同时分析制冷、总用电、供暖和峰值变化；
15. 归档 Excel、EPW 和完整运行目录。
